### `patches/09-admin-enable-department.patch`

Основан только на bbf7a39, изменяет `src/domain/services/admin_service.py` и `src/application/services/admin_service.py`.

- Application enable загружает назначенный Department либо передаёт пустой Department для Admin без отдела.

- Admin без отдела включается; выключенный отдел можно сначала включить либо снять привязку Admin и затем включить сотрудника.
