## Совместимость

- Фабрики сохраняют существующие keyword-вызовы за счёт optional actor. Новый actor передаётся проверенным прикладным Admin, не принимается от пользователя через request body.
- Изменение административного JSON с VO на строку — необходимая смена внешнего формата по прямому решению владельца; потребители административного API должны использовать строковый контракт.
- В01 изменены комментарии к user_action только для особого CREATED, runtime-флаг и общая positive-ID validation сохранены. Иные переходы не ослаблены.
- Существующие persisted owner-actor строки не получают вымышленного Admin. Исправление действует для новых операций.
- После03 уже выданный JWT с прежним exp сам не изменяется. Defaults не доказывают параметры реального env. Истинный first-login старого многократно ротированного refresh может быть утрачен: patch сохраняет доступный дедлайн без продления, но строгий новый срок для таких сессий требует переходного режима, например завершения старых сессий.
- Нет нового PostgreSQL-драйвера, автоматических серверных повторов, UNIQUE отношения1:N или изменения workflow финализации отключённого клиента.
