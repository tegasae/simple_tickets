# Реестр функций и приёмка

F-01–F-05 появились как изменения поведения существующих точек входа между `5288dea` и `869cd42`. F-06–F-08 охватывают обязательные новые механизмы, F-09–F-12 описывают предлагаемые исправления впервые выявленных прежних отклонений. У столбцов «Полнота» и «Исход» разные значения. Под полнотой понимаются указанные в строке критерии в штатном FastAPI и SQLite. Будущий адаптер PostgreSQL и реальная выкладка отмечены отдельно. [Снимок и Git diff](input-state.md)
