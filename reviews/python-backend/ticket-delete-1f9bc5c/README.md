# Отдельное право физического удаления заявки

Базовый коммит `1f9bc5cd2d3f3f3798880fa826a40c1fe2c24039`, ветка `api-new-client-scheme` репозитория `tegasae/simple_tickets`. Патч можно применить самостоятельно. [Патч](03-separate-ticket-delete-permission.patch)

- `DELETE /admin/tickets/{id}` требует административное право `ticket.delete`. Оно появится в каталоге `GET /admin/roles/admin/permissions`. Выдача выполняется явным назначением обычной административной роли.
- `ticket.canceled` применяется для отмены и отклонения. При его наличии без `ticket.delete` физическое удаление возвращает `403`.
- Текущая допустимость статусов сохранена. При разрешённом удалении внутренняя и связанная пользовательская заявки вместе с их статусами и комментариями удаляются в одной транзакции. Отдельная запись об удалении не создаётся. Результаты идемпотентных запросов находятся в отдельном хранилище и подчиняются сроку действия ключа.

Проверки через FastAPI с временной SQLite используют роли ровно с одним правом. Проверены отказ в удалении и успешная отмена с `ticket.canceled`, отказ в отмене с `ticket.delete`, физическое удаление активной и завершённой отменой пары и очистка обеих историй и комментариев.

Выполни команды из корня репозитория.

```bash
patch_file=reviews/python-backend/ticket-delete-1f9bc5c/03-separate-ticket-delete-permission.patch
git apply --check "$patch_file"
git apply "$patch_file"
python -m pytest
```

На исходном коде все три новые проверки не прошли. В частности, право отмены позволяло получить `204` на физическое удаление. После применения патча штатный прогон дал 22 успешных теста. Вместе с патчами штатных регрессий и создания отдела прошли 35 тестов.
