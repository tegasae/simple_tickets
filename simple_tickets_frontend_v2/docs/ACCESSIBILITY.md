# Доступность

Целевой уровень проекта — WCAG 2.2 AA. Предложение DEC-014 применяется уже к первой вертикали входа, восстановления, списка и карточки на чтение. Проверки ниже предстоят в процессе реализации. [DEC-014, DEC-016](DECISIONS.md) · [WCAG 2.2](https://www.w3.org/TR/WCAG22/)

## Приёмка

1. Статическая проверка структуры и имён сопровождается компонентными тестами поведения клавиатуры и фокуса.
2. Автоматический анализ доступности запускается для ключевых состояний, включая ошибки, диалоги и пустые результаты. Ручной сценарий выполняется клавиатурой и хотя бы с одним распространённым экранным считывателем на поддерживаемой платформе.
3. Фиксируются браузер, устройство, масштаб, тема, роль, состояние, критерий WCAG и результат. Поддержку иных платформ и тем подтверждают на репрезентативном наборе. Доступность оформления и сценариев подтверждается фактическими результатами.
