# Независимая первичная карта Python и SQLite

Основной источник для руководства — published, `1e69ee8a6368d8bd1bf9971e4a7501f879e2cf69`. Локальный d497e75 с незакоммиченными материалами служит источником контекста. `readme.md:1–9` описывает ещё постановку проекта. Действующий состав точек входа даёт `src/web/main.py::create_app:37–51`.

- Действующий API — FastAPI `src.web.main:app`, синхронные HTTP-обработчики. `src/web/dependencies/services.py::get_uow:22–32` создаёт файловое SQLite-соединение для запроса и закрывает его после. `ApplicationServiceFactory` связывает UoW с командами и запросами. Сервисы приложения загружают акторов, права и агрегаты, домен проверяет переходы, SQLite-адаптеры используют ABC, BaseRepository, Gateway и Mapper. Другие entry points надо описывать по фактически подключённому приложению.
- `Ticket` и `TicketUser` имеют отдельные истории. `src/domain/services/ticket_sync_service.py::TicketSyncService:26` синхронизирует пару в явной команде. `TicketApplicationService._save_and_to_dto:1236` сохраняет оба агрегата одним коммитом, optimistic lock сверяет версии корней. Удаление `ticket.delete` отдельно от отмены и утверждённого workflow. `TicketApplicationService.execute:950` использует существующий глобальный `ticket.executed`. Новые области department/own документировать как C-10, `docs/futher/ticket_execution_permissions.md:3`.
- `db/schema.sql:1–217` содержит раздельные данные сотрудника, Admin/User, аккаунта, клиента, отдела, ролей, заявок и историй. Изменения версии и двух служебных таблиц обрабатывает `scripts/migrate_backend_storage.py::migrate:96` в одной транзакции. Это ограниченная миграция со сверкой ожидаемого DDL, отдельные изменения даты роли/срочности требуется учитывать при оценке старой БД.
- `src/web/dependencies/auth.py::get_auth_manager_admin:85` и `get_auth_manager_user:98` используют общий `SharedSessionAuthManager`. `src/web/config.py::Settings:11` задаёт 5 мин/7 суток и требует явно заданный новый ключ. `SharedSessionAuthManager.refresh:46` ротирует токен при неизменном абсолютном сроке, хранится хеш и идентификаторы субъекта. Published runtime использует основную БД даже при наличии совместимых полей старого конфигуратора. Локальный снимок имеет старый TokenService и process-local TokenStorageMemory, нет новых записей в DDL.
- Действующие права — `AdminPermission` и `UserPermission`, `src/domain/rbac/permissions.py:14,45`. Эффективные права объединяются через `Authorizer.permissions_of:17`.
