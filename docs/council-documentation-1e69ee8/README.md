## Проверка и сборка

Три эксперта в ранее использованных независимых сессиях подготовили первичные карты, затем провели перекрёстную сверку. Арбитр работал в отдельной восстановленной сессии с назначенной моделью `gpt-6.1-terra` и общими исходными материалами. Заключение указывает объём его фактической проверки.

Для воспроизводимого обновления используйте [инструкцию сборки](build/README.md). Два Markdown — полные источники. В [diagrams/](diagrams/) рядом с картинками находятся исходники Graphviz. В техническом комплекте приложены перечни, сформированные по исходникам, временной SQLite и работающему OpenAPI.

Результаты размещены в отдельном каталоге. Изменения работы консилиума доступны как невключённые в индекс файлы Git.
