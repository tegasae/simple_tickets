# Реестр источников

**Код** отражает фактическое поведение только для замороженного снимка. **Решение владельца** фиксирует намерение и применимость к рабочему процессу. **Рекомендация** описывает предложенный подход. **План** относится к будущему. Тест свидетельствует об отдельном выполненном сценарии на указанной версии.

## Подтверждения из доступного обсуждения

| ID | Источник/тема | Значение |
|---|---|---|
| C-01 | Постановка задачи о документации, 28.11.2026 | Шесть названий и смысл дополнительного права горячей линии, название временное. |
| C-02 | Обсуждение #28 в этой переписке | Самоназначение для рекомендованной работы с правом горячей линии; при специальном старте это право нужно уже назначенному исполнителю. Обычная работа по назначению остаётся доступной по своему праву. |
| C-03 | Ответы владельца об отключении | Проверку закрывают при отключении владельца и отдельно контакта. Сохранившуюся активную работу после отключения клиента может подтвердить Admin. |
| C-04 | Пояснения о контактах и отделах | Контакт связаной заявки обязателен. Изменение контакта включает принятые/отложенные заявки и начальные статусы. Нельзя менять отдел при текущем назначении и включать сотрудника с отключённым отделом. |
| C-05 | Обсуждение патча 01 и JSON | Внешнюю заявку, записанную со слов User, по смыслу сделал User. Первая запись от его имени. Комментарии выводятся строками. |
| C-06 | Ответы о создании отдела и PUT профиля | Сохранять переданный enabled, default true. Пропуск отдела в профиле должен сохранять назначение, 0 — снимать с обычной проверкой. Разрыв G-01 описан отдельно. |
| C-07 | Обсуждение физического удаления | Отдельное право, ограниченный круг, нет обязательной истории удаления. |
| C-08 | Обсуждение N01, перехода и TTL | Единое хранилище, атомарный отзыв, абсолютные 7 суток refresh, access 5 минут, старые refresh завершаются при переходе, числовые версии сохраняются при нормализации NULL. |
| C-09 | Обсуждение N06, сбоя и повторов | Необязательный ключ для созданий, пара субъект + ключ, 24 часа, повторяет клиент. При неопределённом результате важно сохранить защиту от дублей. |
| C-10 | Уточнение `/execute` и запись от 28.11.2026 | Будущие области сохранены в `docs/futher/ticket_execution_permissions.md`. Три области рекомендованы консилиумом, нынешнее право глобальное. |
| C-11 | Обсуждения архитектуры и запуска | Контракты ABC, BaseRepository, Gateway, Mapper и явные бизнес-действия. События, команды, outbox, асинхронность и переносимость обсуждались как развитие. Bootstrap нужен в будущем. |
| C-12 | Ответы владельца в текущей задаче, 28.11.2026 | Действующий код из GitHub `1e69ee8`, локальные материалы как свидетельства. «Обычный сотрудник» — базовый внутренний профиль, «Ведущий инженер» — переименованный «Опытный инженер». |
| C-13 | Ответы владельца в текущей задаче, 28.11.2026 | Два новых диспетчерских права входят в рекомендуемый профиль Менеджера. Рекомендация от сотрудника клиента не считается решением и подлежит отключению. |
