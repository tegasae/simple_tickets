## Версия и изоляция

Основной снимок `1e69ee8a6368d8bd1bf9971e4a7501f879e2cf69`. ## Команды повторения для опубликованной версии

Замените `qa_source` путём к чистому временно экспортированному каталогу с точным снимком. Скопируйте туда только `src/`, `utils/`, `tests/`, `db/schema.sql`, `pytest.ini` и файлы зависимостей. Для миграционной проверки дополнительно нужен `scripts/migrate_backend_storage.py`. SHA проверяется до экспорта. Исходный репозиторий физически отделён от временного каталога.

```bash
docs_root="$PWD"
qa_source=/tmp/frozen-simple-tickets
qa_temp=$(mktemp -d)
python3.12 -m venv "$qa_temp/venv"
qa_python="$qa_temp/venv/bin/python"
"$qa_python" -m pip install -r "$docs_root/meta/requirements-resolved.txt"
cd "$qa_source"
env -i PATH=/usr/bin:/bin PYTHONDONTWRITEBYTECODE=1 "$qa_python" -m pytest \
  -o addopts='' -q -p no:cacheprovider --tb=short --basetemp="$qa_temp/pytest"
env -i PATH=/usr/bin:/bin PYTHONDONTWRITEBYTECODE=1 "$qa_python" "$docs_root/build/verify_api.py"
```

Для получения контрактов и PRAGMA используйте команду `runtime_snapshot.py` из [инструкции сборки](../build/README.md). Примеры опираются на ответы выбранного снимка; идентификаторы и данные входа создаются заново. Для проверки запуска Uvicorn применяется синтетическая схема из раздела 9. Эмпирическая производительность, релизный образ и рабочая база при этой проверке не оценивались.
