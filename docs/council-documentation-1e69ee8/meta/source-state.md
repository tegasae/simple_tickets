Скрипт объединяет пути из `git ls-files --cached -z` и `git ls-files --others --exclude-standard -z`, затем читает байты рабочих файлов этих путей. У обычного файла сохраняет относительный путь, SHA-256 байтов и признак выполнения владельцем. Поддерживаются записи об отсутствующем пути и исключённой ссылке. На опубликованном снимке используется `git ls-tree -r` с выборочным `git archive`. Отсортированный по пути манифест записывается как UTF-8 JSON c `ensure_ascii=False, sort_keys=True, separators=(",", ":")` и завершающим LF. Отпечаток равен SHA-256 всего этого файла.

Оба снимка исключают .env и варианты, рабочие файлы БД и SQL-дампы с данными, тестовые архивы и двоичные сборки, кеши, зависимости и исходники фронтендов. Включены код, документирующий текст, конфигурация, миграции и текстовые результаты прежних проходов по фильтру в скрипте. Имя нового каталога из расчёта исключается. Перед финальным сравнением фильтр уточнили до единственного SQL-входа `db/schema.sql`. Из уже сохранённого начального манифеста исключён путь `db/admins.sql`. Сравнение рассчитано с одним фильтром для начала и конца. Бинарный учебный PDF из прежней ветки известен по Git, основной источник его содержания — текстовая заметка. Локальные записи доступны как пути в манифесте, их отпечаток не смешивается с кодом избранного снимка.
