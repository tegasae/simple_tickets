# Запросы для следующих этапов

Во всех этапах действует без исключений: Единственная разрешённая ветка репозитория simple_tickets — test-deploy: только её исходники, история, коммиты и артефакты. Запрещены чтение, поиск, сравнение, получение (fetch), checkout, merge, cherry-pick, создание и изменение других веток, включая через GitHub API, веб-интерфейс и CI. Исключений нет. При отсутствии нужных файлов в test-deploy сообщи BLOCKED; не ищи их в других ветках.

## После утверждения архитектуры (STOP A)

Утверждаю согласованный план реализации [указать версию плана или ограничения]. Выполни этапы C и D по AGENTS.md. Делегируй задачи с непересекающимися областями файлов; организуй независимое security/QA/reviewer ревью. Не изменяй исходники и не развёртывай на сервере. Покажи diff, проверку защищённых деревьев, результаты сборки/тестов (PASS/FAIL/NOT RUN), нерешённые замечания и порядок передачи изменений в test-deploy. Если в test-deploy не хватает исходников или нельзя подтвердить базовый SHA, останови соответствующую часть. Не используй другую ветку даже для передачи результата; при необходимости предоставь diff.
