## Следующая контрольная точка

Следующая контрольная точка — релизная приёмка I5. Размещение v3 должно отдельно обслуживать JSON-каталоги на том же origin. Для проверки нужны рабочий стенд, составы ролей и согласованная нагрузка. [План](IMPLEMENTATION_PLAN.md) · [Размещение](RUNTIME_CONFIGURATION.md#размещение).

Отдельная очередь «На проверку» ждёт решения DEC-008. В I3 используется исходная подпись владельца по DEC-026. Перед выпуском предстоит проверить штатные версии backend, reverse proxy, поддерживаемые браузеры, экранный считыватель и эксплуатационную нагрузку. [Риски](RISKS.md) · [Стратегия](TESTING_STRATEGY.md).
