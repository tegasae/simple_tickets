## Готовность к началу

**CONDITIONALLY READY.** Существующий API поддерживает предложенную первую вертикаль без изменения backend. Для начала нужны явное разрешение владельца на реализацию I1, согласование стека, границ I1 и хранения rotating refresh (DEC-010/011/016), доступ к изолированному FastAPI/SQLite с тестовыми субъектами и подтверждённым dev proxy. Точная матрица Node/npm проверяется на подготовке этой итерации перед установкой.

Очередь Admin «На проверку» (DEC-008) и альтернативная подпись CTA (DEC-009) относятся к следующим итерациям. Для выпуска остаются согласование размещения v3, реальные составы ролей/профили нагрузки и выполнение эксплуатационной приёмки. Известный backend-контракт не блокирует исходный read-only сценарий. Условная запись по версии, вложения, bulk и update определения роли за пределами согласуемого первого релиза. [Риски](RISKS.md).

Программная реализация, перенос файлов, установка пакетов, сборка и прогоны приложения/тестов не выполнялись. Открытые критерии проверяются на следующих этапах. [Стратегия](TESTING_STRATEGY.md).
