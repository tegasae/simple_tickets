# Функциональные требования

Приоритеты MoSCoW относятся к предлагаемому объёму первого релиза. Must — обязательный сценарий согласованной области, Should — ценная следующая возможность, Could — опция, Won’t — исключение из релиза. Статус утверждения решения указан в [DECISIONS.md](DECISIONS.md). Категории Admin в таблице описывают задачи, фактические права проверяются по [матрице](PERMISSIONS_MATRIX.md).

## FR-019

Изменение текста в уже опубликованном языке является самостоятельным критерием приёмки. Оно должно работать и при единственном доступном языке. [Механизм публикации словарей](ARCHITECTURE.md#10-локализация-и-редактируемые-тексты-интерфейса) · [Сценарий J-019](USER_JOURNEYS.md#j-019--обновить-тексты-интерфейса).
