Из v2 переиспользованы состав полей и порядок связей. Справочники и запись вынесены в API I2. Новых зависимостей нет. Тексты и доступные имена по-прежнему используют стабильные ключи. [Архитектура](ARCHITECTURE.md).

## Запись и ограничения

- После ошибки отдельного запроса сохраняются подтверждённые поля и незавершённый черновик. При конфликте интерфейс показывает серверное и черновое значения. Если первая сверка неопределённого PATCH совпала с желаемым значением, окончательная пользовательская сверка снова проверяет это поле и сохраняет черновик при более позднем расхождении.
- Pre-read обнаруживает уже видимое расхождение. Текущий API не поддерживает `If-Match`, поэтому гонка между чтением и записью остаётся возможной. Автоматической переотправки PATCH/DELETE нет.
- Для создания и комментария ручной повтор неопределённой операции использует тот же ключ и то же содержание. Клиент останавливает повтор после 23 часов от первой отправки с запасом к серверному сроку хранения 24 часа. Неизвестный результат не превращается автоматически в новую запись.
- Синтетические профили включают читателя, автора без права просмотра и оператора, плюс отдельный вариант прав для проверки рекомендации. Рабочие переходы и управление справочниками остаются в следующих итерациях. [Контракт](API_CONTRACT.md) · [Матрица](PERMISSIONS_MATRIX.md).
