# Отчёт по темам и редактируемым текстам

**BK-013 и BK-014 выполнены** в `frontend_new` на базе `f3929b0`. Рабочее место Admin и экран входа используют отдельно публикуемые каталоги на том же origin. [Инструкция по публикации](RUNTIME_CONFIGURATION.md) · [Решения DEC-023, DEC-024 и DEC-028](DECISIONS.md#реестр).

- **FR-018.** В стартовом каталоге есть «1С 8.3», «Классика», «Футуризм» и «Barbie». Переключатель строится по JSON и применяет проверенные CSS-токены. При ошибке каталога доступна встроенная «Классика».
- **FR-019 · Важно.** Стартовый русский словарь перечисляет 406 ключей. Подписи кнопок, диалогов и другие тексты обновляются даже с одним опубликованным языком. Смена языка обновляет заголовки, доступные имена, форматирование и уже показанные ошибки. При отсутствии перевода используется русский резервный текст.
- Настройки загружаются независимо от входа и прав. Переключение темы и языка сохраняет текущую сессию, ввод и фокус элемента управления. В локальном хранилище сохраняются только выбранные ID. [Архитектура](ARCHITECTURE.md#9-каталог-тем-после-развёртывания).
