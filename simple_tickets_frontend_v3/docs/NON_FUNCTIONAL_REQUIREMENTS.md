# Нефункциональные требования

Числовые пороги указаны как нормы стандарта, факты текущей конфигурации или предлагаемые цели, которые проверяются на согласованном профиле нагрузки. [Решения](DECISIONS.md) · [Стратегия проверки](TESTING_STRATEGY.md).

| ID | Область | Требование | Проверка и критерий | Решения |
|---|---|---|---|---|
| NFR-001 | Архитектура | Разделить сессию, API-адаптеры, состояние функций и представление. Нормализовать Ticket для списка и карточки одним адаптером. | Review импортов и unit-фикстуры общего формата. | DEC-011, DEC-016, DEC-017 |
| NFR-002 | Надёжность | Изолировать поколения запросов, single-flight refresh, дедуплицировать отправку и сохранять ввод при сбоях. | Поздний ответ не меняет новый контекст. Неизвестный PATCH не повторяется автоматически. Расхождение изменяемого поля открывает сценарий сверки с сохранённым вводом. | DEC-012, DEC-017 |
| NFR-003 | Безопасность | Проверять актуальные права, фиксировать API origin, очищать токены, кэш и черновики. PII и credential отсутствуют в URL, логах и постоянном хранилище. | Admin A → logout → Admin B, данные A недоступны. Проверить 403, отзыв прав, отсутствие Bearer у другого origin и отсутствие отображения активного пользовательского HTML. | DEC-001, DEC-010, DEC-017 |
| NFR-004 | Производительность | Пагинировать после фильтра и сортировки, ограничить DOM текущей страницей и исключить лишние загрузки. Измерять байты, время API, отрисовку и отклик поиска. | Предлагаемый ориентир p95 локальной фильтрации и отрисовки страницы до 300 мс на согласованных устройстве и наборе очереди. Пороги API утверждаются по baseline. | DEC-013 |
| NFR-005 | Юзабилити | Сохранять контекст заявки, фильтров и выделения. Различать загрузку, пустоту, отказ, частичный результат и успех. | Модерируемая проверка переключения, назначения, hotline и восстановления. Фиксировать потерю контекста, ошибки, время и число действий. | DEC-003, DEC-004, DEC-012, DEC-014 |
| NFR-006 | Доступность | WCAG 2.2 AA как целевой уровень. Видимый фокус, клавиатура, контраст, семантика форм, таблиц и сообщений. | Автоматическая и ручная проверка, screen reader, 200% zoom, reflow 320 CSS px с учётом двумерных таблиц. Устранить препятствия ключевым потокам. | DEC-014 |
| NFR-007 | Сопровождаемость | Правила API, прав и UI локализованы. Публичная конфигурация отдельна для v3, версии и lockfile фиксируются при подготовке. | Чистая установка и сборка по закреплённой матрице при реализации, review каждой новой зависимости и актуальность документации. | DEC-011, DEC-017, DEC-019 |
| NFR-008 | Тестируемость | Изолируемый transport и capability profiles, контракты на отдельной SQLite. Доказательства связаны с требованиями. | Unit/component, контракт, E2E, доступность и сбои. Каждый Must имеет успешную и отрицательную или граничную проверку. | DEC-011, DEC-014, DEC-016 |

Реальные объёмы, устройства и бюджеты времени восстановления уточняются до эксплуатации. [Риски](RISKS.md).
