# Темы, языки и тексты Frontend v3

**Важно.** Темы, языки и тексты интерфейса публикуются отдельными JSON-файлами. После публикации обновите страницу обычным способом. Браузер перечитает конфигурацию на прежней сборке. [DEC-023 и DEC-024](DECISIONS.md#реестр).

| Путь браузера | Что публикуется | Стартовый файл |
|---|---|---|
| `/config/themes.json` | Каталог тем и тема по умолчанию | [themes.json](../public/config/themes.json) |
| `/config/locales.json` | Каталог языков и язык по умолчанию | [locales.json](../public/config/locales.json) |
| `/config/locales/{id}.json` | Словарь языка | [Полный русский словарь](../public/config/locales/ru-RU.json) |

## Добавить тему

1. Скопируйте опубликованный `themes.json` и добавьте в массив `themes` запись с новым `id`, отображаемым `label` и `tokens`. Начальный набор содержит «1С 8.3», «Классика», «Футуризм» и «Barbie».
2. Переиспользуйте токены подходящей темы и измените нужные значения. Идентификатор длиной до 32 символов начинается со строчной латинской буквы. Допустимы строчные латинские буквы, цифры и дефисы. `defaultTheme` указывает на ID из каталога.
3. Замените опубликованный `themes.json` целиком. После обновления страницы новая тема появится в переключателе. При недоступном или повреждённом каталоге применяется встроенная «Классика».

Пример записи для массива `themes`.

```json
{
  "id": "lagoon",
  "label": "Лагуна",
  "tokens": {
    "--accent": "#18625D",
    "--accent-dark": "#154B46",
    "--accent-hover": "#154B46",
    "--accent-soft": "#E2F4EF",
    "--on-accent": "#FFFFFF"
  }
}
```

У каталога `version` равна `1`, а `themes` содержит от одной до 32 тем с уникальными ID. Пропущенные токены наследуются из встроенной «Классики». Палитры используют значения `#RRGGBB`. Поддерживаются `--bg`, `--panel`, `--panel-soft`, `--text`, `--muted`, `--line`, `--line-strong`, `--accent`, `--accent-dark`, `--accent-hover`, `--accent-soft`, `--on-accent`, `--focus`, `--danger` и `--danger-soft`. `--radius` и `--radius-sm` принимают целые значения от `0px` до `24px`, `--control-height` от `40px` до `56px`, `--scheme` принимает `light` или `dark`. Для новой палитры проверьте контраст текста, акцентных кнопок и фокуса. [Базовые палитры](../public/config/themes.json).

## Обновить подпись на действующем языке

В опубликованном `/config/locales/ru-RU.json` измените значение нужного ключа внутри `messages`. Например, `login.submit` задаёт текст кнопки входа, а `work.closeTitle` задаёт заголовок окна закрытия вкладки. Полный перечень ключей поставляется в русском словаре. Обновление работает даже при единственном русском языке.

Сохраняйте имена параметров, таких как `{id}` или `{count}`. Их порядок в предложении можно менять. Переводы отображаются как текст. Отсутствующее, пустое или недопустимое значение заменяется соответствующим встроенным русским текстом. [Шаблон всех сообщений](../public/config/locales/ru-RU.json).

## Добавить язык

1. Подготовьте `/config/locales/en-US.json`. Для другого языка используйте его канонический тег BCP 47 длиной до 63 символов. Имя файла, `language` словаря и `id` каталога должны совпадать.

   ```json
   {
     "version": 1,
     "language": "en-US",
     "messages": {
       "login.title": "Sign in",
       "login.submit": "Continue",
       "work.closeTitle": "Unsaved changes in ticket #{id}"
     }
   }
   ```

2. Опубликуйте словарь, затем добавьте `{"id":"en-US","label":"English"}` в `languages` опубликованного `locales.json`. В каталоге оставьте `version: 1` и `defaultLanguage`, присутствующий в списке языков.
3. Обновите страницу и выберите язык. Интерфейс применит доступные переводы, локаль дат и чисел и атрибут `lang`. Для остальных ключей действует встроенный русский словарь. При ошибке загрузки сохранённого языка приложение остаётся доступно на русском, а предпочтение сохраняется для последующих обновлений.

## Размещение

Vite копирует `public/config/` в `dist/config/`. Для локального preview можно менять копии JSON в `dist/config/` после сборки. При размещении v3 храните публикуемые каталоги отдельно от файлов приложения и заменяйте каждый JSON атомарно. Так следующая поставка сборки сохраняет отдельно опубликованные настройки. Файлы отдаются в UTF-8 с `Content-Type: application/json` и `Cache-Control: no-store`. Загрузчик принимает до 256 КиБ на файл.

Пример блоков отдельного виртуального хоста Nginx. В примере файлы настроек лежат в `/srv/simple-tickets-runtime/config/`, а сборка в `/srv/simple-tickets-v3/dist/`. Хост и порт FastAPI задаются для конкретного стенда.

```nginx
root /srv/simple-tickets-v3/dist;

location = /config { return 404; }
location ^~ /config/ {
    root /srv/simple-tickets-runtime;
    types { application/json json; }
    add_header Cache-Control "no-store" always;
    try_files $uri =404;
}

location = /api { return 404; }
location ^~ /api/ {
    proxy_pass http://fastapi:8000/;
}

location ^~ /assets/ {
    add_header Cache-Control "public, max-age=31536000, immutable";
    try_files $uri =404;
}
location / {
    add_header Cache-Control "no-cache";
    try_files $uri /index.html;
}
```

Конфигурация общая для браузеров и читается без авторизации. Владельцы стенда управляют доступом на запись к файлам. Браузер сохраняет только ID выбранной темы и языка в локальных предпочтениях. [Архитектура](ARCHITECTURE.md#9-каталог-тем-после-развёртывания) · [Отчёт](APPEARANCE_REPORT.md).
