# Реестр рисков

Оценки вероятности и последствий экспертные. Критичность относится к предлагаемому объёму, уточняется по результатам измерений и контрактных тестов.

| ID | Риск | Вероятность / последствия / критичность | Смягчение и проверка | Ответственный |
|---|---|---|---|---|
| R-01 | Ротация refresh при reload, поздний ответ или копия вкладки | Средняя / сорванный вход или смешение сессий / высокая | Изолировать поколение, single-flight, safe logout и профиль TC-001. Остаточный риск JS-доступного refresh согласовать. | React, QA |
| R-02 | Черновик теряется при смене карточки или его основа устаревает | Средняя / потеря работы / высокая | Черновик по ID, явный выход, pre-read и сверка полей, сценарии двух карточек. | React, UX |
| R-03 | Неизвестный результат мутации, повтор или 409 | Средняя / дубликат или перезапись / высокая | Фиксированный ключ намерения для поддерживаемых POST, перечтение, раздельное сохранение черновика. Отсутствие условной записи остаётся риском. | FastAPI, QA |
| R-04 | Два Admin пытаются взять заявку, изменились состояние или исполнитель | Средняя / неверное представление текущей работы / высокая | Один атомарный PATCH, серверные условия и конкурентный TC-010. | FastAPI, QA |
| R-05 | Grant и revoke применены частично, собственные права изменились | Средняя / неочевидный доступ / высокая | Минимальные дельты и отдельные ответы, перезапрос профиля и прав. | React, QA |
| R-06 | Удаление влечёт потерю связанной заявки и истории | Низкая при ограничении прав / необратимая потеря / высокая | Явное подтверждение области, право отдельно от отмены, тесты на синтетических записях. | UX, QA |
| R-07 | Реальная очередь слишком велика для клиентской обработки | Неизвестная / медленная работа / высокая | Замерить типичный и пиковый объём, использовать scoped API, ограничить DOM и согласовать бюджеты. | React, Lead |
| R-08 | Текущий Dockerfile строит v2, origin и SPA fallback v3 не согласованы | Высокая до выбора / блок выпуска / высокая | Подтвердить test proxy, отдельный путь доставки, HTTPS и smoke на релизном маршруте. | Lead, React |
| R-09 | Очередь Admin воспринимается как подтверждение User | Средняя / ошибочное ожидание процесса / средняя | Отдельный DEC-008, ясные названия и интерфейс только Admin. | UX, Lead |
| R-10 | Неполный PUT устанавливает defaults, служебный PATCH получает неподходящее поле | Средняя / потеря данных или отказ / высокая | Контракт PUT, актуальная основа, отдельные команды отдела, проверка полезной нагрузки и 422/400. | React, FastAPI |
| R-11 | Клавиатура, фокус или reflow блокируют работу | Средняя / недоступная основная задача / высокая | WCAG-план, ручные сценарии и реальные участники помимо автоматических проверок. | UX, QA |
| R-12 | Работа вне `frontend_new` или за пределами v3 | Низкая при изоляции / нарушение регламента / высокая | Проверка HEAD и области tracked/untracked/staged/ignored, отдельная рабочая копия. | Lead, QA |
